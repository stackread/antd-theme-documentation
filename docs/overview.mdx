# Components

72 pages, one per component, grouped by what they are for.

Each page carries working specimens, built on Ant Design. Where
Ant Design has no equivalent, the page says so and says what was left out -
those notes are marked **Omitted** and carry the count of specimens affected.

<div className="cards">

**Layout** - flex, header, rules, spacing.

**Containers** - accordion, card, flyout, modal, panel, popover, tabs.

**Navigation** - buttons, breadcrumbs, menus, pagination, steps, tree.

**Display** - 21 pages, from avatar to tour.

**Forms** - seven groups of controls, from layout to date and time.

**Tables** - basic, custom, and one that sorts and filters itself.

</div>

## Deliberately not here

| component | why not here |
|---|---|
| Aspect ratio, Beacon, Bottom bar, Drag and drop, Illustrations | no Ant Design counterpart |
| Data grid (8 pages) | a component of its own size; Ant Design's `Table` covers a different job |
| Templates, Sitewide search | page scaffolding rather than components |
| Editors and syntax | a Markdown editor, which a theme does not supply |
| Facet, Key pad menu | no counterpart |

Naming them is the point. An omitted component and a forgotten one look the
same from outside.
