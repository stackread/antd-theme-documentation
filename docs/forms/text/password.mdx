# Password field

<FormRowCallout />

For entering a password. It renders `<input type="password">`, so what is typed
appears as dots and is kept out of the browser's ordinary autofill and
copy paths.

```tsx interactive
import React from 'react';
import { Input, Space, Switch } from 'antd';

export default () => {
  const [compressed, setCompressed] = React.useState(false);
  const [disabled, setDisabled] = React.useState(false);
  const [invalid, setInvalid] = React.useState(false);

  const toggles = [
    ['Compressed', compressed, setCompressed],
    ['Disabled', disabled, setDisabled],
    ['Invalid', invalid, setInvalid],
  ];

  return (
    <Space orientation="vertical" size={16} style={{ display: 'flex', maxInlineSize: 400 }}>
      <Space size={16} wrap>
        {toggles.map(([name, value, setIt]) => (
          <label key={name} style={{ display: 'inline-flex', alignItems: 'center', gap: 8 }}>
            <Switch size="small" checked={value} onChange={setIt} />
            {name}
          </label>
        ))}
      </Space>

      <Input.Password
        aria-label="A password field"
        placeholder="Password"
        visibilityToggle={false}
        size={compressed ? 'small' : 'middle'}
        disabled={disabled}
        status={invalid ? 'error' : undefined}
      />
    </Space>
  );
};
```

## Showing passwords

Let the reader turn the dots off. A password typed blind is a password typed
twice, and the reader who cannot see what they typed is the one most likely to
be locked out.

The control is a toggle with two states, so it needs a name that says which
state it is in - "Show password" while hidden, "Hide password" while shown.

```tsx interactive
import React from 'react';
import { Input, Space } from 'antd';

export default () => (
  <Space orientation="vertical" size={16} style={{ display: 'flex', maxInlineSize: 400 }}>
    <Input.Password
      aria-label="A password that can be shown"
      placeholder="Password"
      defaultValue="hunter2"
    />
  </Space>
);
```
